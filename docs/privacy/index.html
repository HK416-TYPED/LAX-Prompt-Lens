Privacy Policy

EFFECTIVE 2026-08-27 · CONTACT LAX@COMFY.ORG

LAX Prompt Lens is a local-first Chrome extension. The developer does not operate a server for the extension and does not receive your prompts, images, API keys, settings, or browsing activity.

Data processed

  • Post URL and public post data. The Danbooru URL you paste is used to request public JSON, tags, metadata, and images from *.donmai.us and cdn.donmai.us.
  • Reference image and instruction. Only after you request visual analysis, the selected image and built-in art-direction instruction are sent to the vision API provider you chose.
  • API credentials. Your key is sent only to the configured endpoint. It is session-only by default and is saved in local Chrome extension storage only when you explicitly enable “Save key.”
  • Settings and results. Preferences are stored locally. Compact mode temporarily keeps the latest URL, prompt, and counts in Chrome session storage.
  • Diagnostics. Failure reports are created locally and are never transmitted to the developer unless you choose to copy and share them.

Use and sharing

Data is used only to retrieve the requested public post, generate and display the requested prompt, remember settings, and diagnose failures. It is not sold or used for advertising, tracking, profiling, analytics, credit decisions, or unrelated purposes.

Necessary transfers occur only to Danbooru/Donmai for public post retrieval and to the vision API you select for the requested analysis. The developer receives no copy. Third-party providers process data under their own terms and privacy policies.

Retention, deletion, and security

The developer retains no user data. Session data expires with Chrome’s extension session. Local settings and an optional saved key remain until you change them, clear extension data, or uninstall the extension. Remote endpoints must use HTTPS; HTTP is accepted only for localhost and 127.0.0.1. The extension executes no remotely hosted code.

Chrome Web Store Limited Use

The extension’s use and transfer of information complies with the Chrome Web Store User Data Policy, including Limited Use. Access is limited to what is necessary for the extension’s prominent, user-facing single purpose.

Changes and contact

Material changes will be published with a new effective date and reflected in the listing and in-product disclosure before taking effect. Questions can be sent to lax@comfy.org.

隐私政策

生效日期 2026-08-27 · 联系邮箱 LAX@COMFY.ORG

LAX Prompt Lens 是本地优先的 Chrome 扩展。开发者没有运营中转服务器，也不会收到你的提示词、图片、API Key、设置或浏览活动。

处理的数据

  • 帖子链接与公开数据：你粘贴的 Danbooru 链接用于请求公开帖子 JSON、标签、元数据与图片。
  • 参考图与分析指令：只有在你主动要求视觉分析后，所选主图和内置指令才会发送到你选择的视觉 API。
  • API 凭证：Key 只发送到所配置接口；默认仅保留于当前会话，只有主动开启“保存 Key”才写入 Chrome 扩展本地存储。
  • 设置、结果与诊断：设置保存在本机，小窗结果暂存在会话存储；故障报告只在本地生成，除非你主动复制并分享。

用途、传输与保留

数据只用于读取所请求的公开帖子、生成并显示提示词、记忆设置与诊断故障，不会出售，也不会用于广告、跟踪、画像、统计或其他无关目的。必要的网络传输只发生在 Danbooru/Donmai 与你选择的视觉 API 之间，开发者不会收到副本。第三方按照其自身政策处理数据。

开发者不保留用户数据。会话数据随扩展会话失效；本地设置与可选保存的 Key 会保留到你修改、清除扩展数据或卸载插件。远程接口必须使用 HTTPS，只有本机 localhost 与 127.0.0.1 可使用 HTTP。插件不执行远程托管代码。

有限使用与联系

插件遵守 Chrome Web Store 用户数据政策与 Limited Use 要求，数据访问仅限完成明确、用户可见的单一用途。政策发生实质变化时会先更新生效日期、商店说明与插件内披露。问题请发送至 lax@comfy.org。
