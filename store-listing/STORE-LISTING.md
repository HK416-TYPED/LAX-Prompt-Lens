## English (default)

### Name

LAX Prompt Lens

### Summary

Extract Danbooru tags and turn reference images into professional Japanese illustration art-direction prompts.

### Detailed description

LAX Prompt Lens turns a Danbooru post URL into prompt material you can use immediately.

Paste a post link to extract its artist, copyright, character, and general tags in clean prompt syntax. With a vision-capable API of your choice, the extension also analyzes the reference image as a Japanese illustration art director, focusing on composition, camera, depth, drawing technique, edge control, color design, lighting, materials, and editorial character.

The result is available in three forms:

- a cleaned Danbooru tag prompt;
- a polished 300–550 word English natural-language art-direction prompt;
- a combined TAG + NL prompt, ready to copy.

Two interfaces fit different workflows. The full Chrome side panel includes previews, provider settings, diagnostics, and separate outputs. Compact mode opens from the toolbar and keeps only the URL, generate, and copy controls, so the page retains its full width.

Privacy and control:

- no analytics, advertising, tracking, or developer-operated server;
- Danbooru requests do not include cross-site cookies;
- the reference image and analysis instruction are sent only after you click Analyze, and only to the vision API you selected;
- API keys are session-only by default and are saved to local Chrome extension storage only if you explicitly enable Save;
- official OpenAI and xAI Grok presets, JarlessAPI, and compatible Responses or Chat Completions endpoints are supported, including a custom endpoint authorized at runtime;
- no remotely hosted code is executed.

A compatible vision API key is required for image analysis. Tag-only extraction does not require an API key. LAX Prompt Lens is an independent tool and is not affiliated with Danbooru, OpenAI, xAI, JarlessAPI, or their operators.

## 简体中文

### 名称

LAX Prompt Lens

### 简短说明

提取 Danbooru 标签，并将参考图转化为专业日系插画 Art Direction 提示词。

### 详细说明

LAX Prompt Lens 可以把 Danbooru 帖子链接转化为可直接使用的提示词素材。

粘贴帖子链接后，插件会提取并清理画师、版权、角色与通用标签，输出符合提示词习惯的标签格式。连接你选择的视觉 API 后，插件还会以日系插画美术指导的角度分析参考图，重点覆盖构图、镜头、空间层次、绘制方法、边缘控制、配色、光照、材质与编辑设计感。

插件会提供三种结果：

- 清理后的 Danbooru 标签提示词；
- 约 300–550 词的英文自然语言 Art Direction 提示词；
- 可一键复制的 TAG + NL 合并提示词。

完整版以 Chrome 侧边栏呈现，包含主图预览、服务设置、诊断信息和分项输出。小窗模式从工具栏打开，只保留链接、生成和复制操作，不占用网页宽度。

隐私与控制：

- 不含统计分析、广告、跟踪或开发者中转服务器；
- 读取 Danbooru 时不携带跨站 Cookie；
- 只有在你点击“提取并分析”后，参考图和分析指令才会发送到你选择的视觉 API；
- API Key 默认只保留在当前浏览器会话中，只有你主动勾选“保存”时才会写入 Chrome 扩展本地存储；
- 支持 OpenAI 官方预设、xAI Grok 官方预设、JarlessAPI、Responses、Chat Completions 以及按需授权的自定义兼容接口；
- 不执行远程托管代码。

视觉分析需要使用者自己的兼容视觉 API Key；仅提取标签不需要 API Key。LAX Prompt Lens 是独立工具，与 Danbooru、OpenAI、xAI、JarlessAPI 及其运营方没有隶属或背书关系。
